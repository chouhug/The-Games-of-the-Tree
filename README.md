# 大樹總會 The Games of the Tree

一個在瀏覽器就能玩的休閒放置遊戲：種一棵 3D 大樹，大樹旁邊的小遊戲都會幫它長大。

**直接玩：** https://chouhug.github.io/The-Games-of-the-Tree/

## 玩法

- **疊疊樂賺錢塔**：看準時機放下積木，賺陽光。疊到新區域會解鎖永久加成。
- **地心挖礦**：鑽頭往下鑽，挖水、礦石、化石。大樹越大，樹根越深，能挖得越深。
- **樹靈**：用化石復原古代種子，孵出樹靈，強化各個小遊戲。
- **樹靈冒險**：帶最多 3 隻樹靈，從大樹出發滑翔到雲海裡的浮島，淨化枯萎、帶回養分。打完一區，那座島會飄到大樹旁邊。
- **大樹**：用陽光、水和養分澆水讓大樹長大，產生樹液，在升級樹上買能力。

每個遊戲的產出都是另一個遊戲需要的東西，繞成一個循環。另外有每日委託、成就和新手教學。

## 技術

- 單一 `index.html`，不需要安裝或建置。
- 3D 大樹用 WebGL 畫，舊手機或沒有顯示卡時會自動改用 Canvas 2D。
- 進度存在瀏覽器的 localStorage；「選單 → 設定」可以匯出存檔碼，換裝置時貼上就能接著玩。
